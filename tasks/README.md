# tasks/ — タスクファイルの運用

各ファイルはエージェント1人（1セッション）が引き継ぎ可能な単位のタスク定義。

## 読み方・進め方
1. 着手前に PROJECT.md → AGENTS.md → ROADMAP.md → 対象タスクファイルの順で読む
2. タスクファイル冒頭の「ステータス」を `in-progress` に更新してから着手する
3. 完了条件を満たしたら `done` に更新し、「作業記録」欄に日付・変更概要・実験ログのchangeRefを追記する
4. 途中で中断する場合も「作業記録」に現在地と次の一手を必ず残す（引き継ぎの生命線）

## ステータス値
`todo` / `in-progress` / `blocked`（理由を記録） / `done`

## 原則
- タスクの「実装方針」は方向づけであり、詳細設計はエージェントの裁量（AGENTS.md §1）
- スコープ外のことに気づいたら、このディレクトリに新しいタスクファイルを起票する（勝手に混ぜない）
- 検証区分と完了条件はタスクファイルが正。迷ったら AGENTS.md §4 に従う
